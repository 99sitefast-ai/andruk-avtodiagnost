# Сайт выездного автодиагноста — ИП Андрук Владимир Васильевич

Статический многостраничный сайт (HTML + CSS + JS, без сборки и зависимостей).
Публикуется через GitHub Pages.

## Страницы

| Файл | Что внутри |
|------|-----------|
| `index.html` | Главная: симптомы, услуги, прайс, порядок выезда |
| `diagnostika.html` | 10 видов диагностики, эндоскопия, осмотр перед покупкой |
| `remont.html` | Ремонт ДВС, КПП, сварка, покраска грузовых, рассрочка |
| `ceny.html` | Прайс, из чего складывается цена, оплата |
| `vyezd.html` | Выезд по Мозырю и всей Беларуси, границы возможностей |
| `kontakty.html` | Телефон, мессенджеры, что сказать при звонке |
| `404.html` | Страница ошибки |

## Структура

```
assets/css/style.css   все стили (переменные в :root в начале файла)
assets/js/app.js       мобильное меню, появление блоков, год в подвале
assets/img/*.jpg       фотографии
```

## Что стоит проверить и заменить

1. **Цены** — в `index.html`, `ceny.html` (блоки `.prow`) указаны «от»: 30 / 30 / 50 / 50 / 100 р.
   Диагностика КПП, тормозов, электрики, дизеля и техосмотр идут как «по факту».
   Если есть точные цены — их надо проставить.
2. **Фотографии** — в `assets/img/` лежат сгенерированные изображения под тему
   (ночь в боксе, моторный отсек, подъёмник, дорога, ноутбук, сварка, покраска, эндоскоп).
   Замените своими фото с объектов, сохранив имена файлов, — вёрстка подстроится.
   Рекомендуемый размер: 1600 px по длинной стороне, JPEG q80.
3. **График работы** — на сайте не указан. Если нужен («круглосуточно», «до 22:00»),
   его надо добавить в `kontakty.html` и в подвал.
4. **География выезда** — в `vyezd.html` перечислены Мозырь, Калинковичи, Речица, Хойники,
   Петриков, Гомель. Поправьте список под реальную зону.
5. **Реквизиты** — сейчас только «ИП Андрук Владимир Васильевич». При необходимости
   добавьте УНП и адрес в подвал всех страниц.

## Локальный просмотр

Просто откройте `index.html` в браузере или запустите:

```bash
python3 -m http.server 8000
```

## Публикация

GitHub Pages: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Файл `.nojekyll` уже добавлен, чтобы GitHub не обрабатывал статику через Jekyll.
